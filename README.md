# 📚 READ&PRACTICE

Образовательная 3D‑игра про учёбу в школе (Three.js + Vite). Ребёнок просыпается дома, собирается,
спускается на лифте, идёт по улице через парк в школу, находит нужный кабинет по расписанию и
проходит уроки в два этапа: **READ** (чтение темы) → **PRACTICE** (задания). За ответы он получает
монеты, опыт и достижения, а монеты тратит в магазине на образы и аксессуары.

## 🚀 Запуск

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173). Сборка для публикации:

```bash
npm run build
```

```bash
npm run preview
```

Готовые файлы окажутся в `dist/`. Это статический сайт, его можно выложить на любой хостинг.

## 🗺️ Что есть в игре

1. **Дом** — квартира в два уровня с лестницей. Надо взять рюкзак и переодеться (из пижамы в
   надетый образ). Ещё можно позавтракать, почистить зубы, выключить будильник, погладить кота,
   пнуть мяч и найти звёзды знаний.
2. **Подъезд** — коридор, двери соседей (в них можно позвонить), бабушка с загадкой, кнопка вызова
   лифта, табло этажей.
3. **Лифт** — двери открываются с анимацией, есть панель с кнопками 1–4, тряска при движении.
   На 1 этаже — вестибюль и выход. Если выйти на 2 или 4 этаже, игра подскажет, что этаж не тот.
4. **Улица** — двор с площадкой (качели раскачиваются), парковка, дорога с работающим светофором и
   машинами, которые останавливаются перед переходом, парк с фонтаном (желание за монетку), собака,
   цветы для полива, таблички с фактами, второй переход с регулировщиком, школьный двор с
   футбольными воротами (за гол дают монеты). Навигация: жёлтые стрелки на земле, указатели
   «Школа ➡», метки над объектами, мини‑карта, стрелка‑компас и расстояние до цели.
5. **Школа (3 этажа)** — холл с гардеробом и расписанием, коридоры, лестница с указателями этажей,
   таблички с номерами кабинетов. Классы с уроками строятся **автоматически** по JSON‑файлам.
   Свободные кабинеты стали столовой, спортзалом, библиотекой, медкабинетом, актовым залом
   (с пианино) и учительской.

**Уроки:** математика, русский язык и английский — полные уроки (5/4/5 страниц чтения и
по 10 заданий). Литература, природоведение, история, география и информатика — короткие бонусные уроки.

### Механики для интереса
- 🦉 Сова Соня — помощница, которая подсказывает, что делать дальше.
- 🔥 Комбо за ответы подряд, 💡 платные подсказки, 🔁 повтор урока.
- ⭐ 10 спрятанных «звёзд знаний», при каждой находке показывается интересный факт.
- 🏅 22 достижения, уровни опыта, оценки в дневнике, конфетти за хорошие результаты.
- 🔊 Озвучка текста и диктант голосом через Web Speech API. Если в браузере его нет, слово
  на пару секунд показывается на экране.
- 📅 Смена учебных дней: на каждый день берутся следующие уроки по кругу. Чтобы закончить день,
  нужно вернуться домой.
- Вся музыка и звуки синтезируются через WebAudio, внешние аудиофайлы не нужны.

## ➕ Как добавить новый урок или предмет

1. Создайте файл `src/lessons/data/<id>.json`. Подключать его в коде не нужно: файлы собираются
   автоматически через `import.meta.glob`.
2. Укажите номер кабинета в поле `room`. Номера кабинетов: этаж 1 — `101`–`104`, этажи 2 и 3 —
   `x01`–`x05`. Кабинет с этим номером сам станет классом с партами, доской, учителем и
   табличкой. Сейчас свободны `103, 104, 204, 205, 304, 305`: там спецкомнаты, и урок их заменит.
3. Чтобы урок появлялся в расписании, добавьте его `id` в `CONFIG.schedule` в `src/config.js`.
   Даже без этого урок доступен для свободной практики: достаточно сесть за парту в его кабинете.

Пример:

```json
{
  "id": "music",
  "subject": "Музыка",
  "room": "204",
  "icon": "🎵",
  "color": "#e84393",
  "teacher": "Анна Викторовна",
  "teacherAvatar": "👩‍🏫",
  "title": "Ноты и звуки",
  "lang": "ru-RU",
  "intro": "Здравствуйте! Сегодня знакомимся с нотами.",
  "practiceCount": 5,
  "read": [
    {
      "title": "Семь нот",
      "pic": "🎼",
      "text": [
        "Всего **семь нот**: до, ре, ми, фа, соль, ля, си.",
        "Ноты записывают на [[нотном стане|Пять параллельных линеек для записи нот]]."
      ],
      "tip": "Запомни: «Каждый Охотник Желает Знать...» — это про цвета радуги, а не про ноты 🙂"
    }
  ],
  "practice": [
    { "type": "input", "q": "Сколько всего нот?", "answer": ["7", "семь"], "hint": "До, ре, ми...", "explain": "До, ре, ми, фа, соль, ля, си — 7 нот." }
  ]
}
```

**Разметка текста:** `**слово**` выделяет слово цветом, `[[слово|подсказка]]` делает жёлтый термин,
по нажатию на который показывается подсказка.

**Необязательные поля урока:** `teacherAvatar`, `teacherColor`, `intro`, `praise`, `poster`
(текст плаката в классе), `lang` (язык озвучки, например `en-US`), `practiceCount` (сколько
случайных заданий брать из списка).

### Типы заданий (`practice[].type`)

| type | Поля | Описание |
|---|---|---|
| `choice` | `q, options[], answer` (текст или индекс), `big?` | выбор одного ответа |
| `truefalse` | `q, answer: true/false` | верно / неверно |
| `input` | `q, answer` (строка или массив вариантов), `placeholder?` | ввод ответа; регистр, «ё» и знаки препинания не важны |
| `match` | `q, pairs: [[левое, правое], ...]` | сопоставление пар |
| `order` | `q, items[]` (в правильном порядке), `join?` | расставить по порядку |
| `math` | `q, gen: {ops:["+","-","×","÷"], min, max, count}` или `examples: [["2 + 2", 4]]` | случайные примеры |
| `dictation` | `q, words[], lang?` | диктант с озвучкой |
| `gap` | `q, text: "м_локо", options[], answer` | вставить пропущенную букву или слово |

Во всех заданиях можно указать `explain` (объяснение показывается после ответа) и `hint`
(платная подсказка).

**Свой тип задания:** добавьте объект в `TASK_TYPES` в `src/lessons/tasks.js`. Метод
`render(el, task, ctx)` должен вернуть `{ check() }` для заданий с кнопкой «Проверить» или
`{ auto: true }`, если задание вызывает `ctx.done(result)` само. Результат: `{ frac: 0..1, answer }`.

## 🛍️ Как добавить предмет в магазин

Добавьте объект в `ITEMS` в `src/shop/items.js`:
- **образ (skin):** цвета `body`, `pants`, `shoes`, `hair`, `skinTone`, форма `shape`
  (`normal | round | tall | mini | robot`) и деталь `extra` (`tie, stripes, cape, robe, astro, dino...`);
- **аксессуар:** `slot` (`hat | glasses | backpack | watch | badge`), `model` (см. `buildHat`,
  `buildGlasses`... в `src/player/CharacterModel.js`) и цвета `color` / `color2`.

## ⚙️ Настройка баланса (`src/config.js`)

- `lesson.realSeconds` — сколько реальных секунд длится урок (по умолчанию 300 с = 30 игровых
  минут). Это значение также меняется в игре: Настройки → «Длина урока».
- `clock.*` — время пробуждения, скорость игровых часов, порог для «ранней пташки».
- `rewards.*` — монеты и опыт за ответы, комбо, бонусы, подсказки, находки.
- `schedule` и `lessonsPerDay` — порядок уроков и их количество в день.

## ⚡ Производительность

- Статическая геометрия каждой локации объединяется в несколько мешей по цветам
  (`BaseScene.finalize`). Так draw calls остаётся немного: в школе около 110, на улице около 380
  вместе с тенями.
- Тени даёт одна направленная лампа, область теней следует за игроком.
- Режим «Быстрая графика» в настройках отключает тени и снижает разрешение рендера.
- Этажи, которые выше игрока, скрываются (режим «кукольного домика»), чтобы камере не мешали
  потолки.

## 💾 Сохранения

Прогресс (монеты, опыт, покупки, оценки, достижения, звёзды, текущая локация и шаг дня)
автоматически сохраняется в `localStorage`: каждые 15 секунд, при переходах между локациями и
при закрытии вкладки. Сбросить прогресс можно в разделе Настройки → «Сбросить весь прогресс».
