# 📚 READ&PRACTICE

Образовательная 3D‑игра про учёбу в школе (Three.js + Vite). Ребёнок просыпается дома, собирается,
спускается на лифте, идёт по улице через парк в школу, находит нужный кабинет по расписанию и
проходит уроки в два этапа: **READ** (чтение темы) → **PRACTICE** (задания). За ответы он получает
монеты, опыт и достижения, а монеты тратит в магазине на образы и аксессуары.

## 🚀 Запуск

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173). Сборка для публикации:

```bash
npm run build
```

```bash
npm run preview
```

Готовые файлы окажутся в `dist/`. Это статический сайт, его можно выложить на любой хостинг.

## 🗺️ Что есть в игре

1. **Дом** — квартира в два уровня с лестницей. Надо взять рюкзак и переодеться (из пижамы в
   надетый образ). Ещё можно позавтракать, почистить зубы, выключить будильник, погладить кота,
   пнуть мяч и найти звёзды знаний.
2. **Подъезд** — коридор, двери соседей (в них можно позвонить), бабушка с загадкой, кнопка вызова
   лифта, табло этажей.
3. **Лифт** — двери открываются с анимацией, есть панель с кнопками 1–4, тряска при движении.
   На 1 этаже — вестибюль и выход. Если выйти на 2 или 4 этаже, игра подскажет, что этаж не тот.
4. **Улица** — двор с площадкой (качели раскачиваются), парковка, дорога с работающим светофором и
   машинами, которые останавливаются перед переходом, парк с фонтаном (желание за монетку), собака,
   цветы для полива, таблички с фактами, второй переход с регулировщиком, школьный двор с
   футбольными воротами (за гол дают монеты). Навигация: жёлтые стрелки на земле, указатели
   «Школа ➡», метки над объектами, мини‑карта, стрелка‑компас и расстояние до цели.
5. **Школа (11 этажей): этаж = класс.** На 1 этаже учится 1 класс, на 11 этаже — 11 класс.
   На каждом этаже есть кабинеты всех предметов этого класса по учебному плану. Между этажами
   можно ходить по лестнице или ездить на школьном лифте (кнопки 1–11). На 1 этаже находятся
   холл с гардеробом, выход, столовая и большой **спортзал**: в нём проходит физкультура всех классов.

### 📚 Учебная программа (148 уроков, 522 страницы чтения)

| Классы | Предметы |
|---|---|
| 1–4 (начальная) | русский язык, литературное чтение, математика, окружающий мир, английский (со 2 кл.), ОРКСЭ (4 кл.), музыка, ИЗО, труд, физкультура |
| 5–6 | русский, литература, английский, математика, история, география, ОДНКНР, музыка, ИЗО, труд, физкультура; с 6 кл. — обществознание и биология |
| 7–9 | математика делится на алгебру, геометрию, вероятность и статистику; добавляются физика и информатика (с 7), химия и ОБЗР (с 8), второй иностранный — немецкий (7–9). Музыка — до 8 класса, ИЗО — до 7, затем МХК |
| 10–11 | русский, литература, английский, алгебра, геометрия, вероятность, информатика, история, обществознание, география, биология, физика, химия, МХК, ОБЗР, физкультура |

Учебный план описан в `src/lessons/curriculum.js`. Каждый день в расписании 4 урока
своего класса: сначала ещё не сданные предметы, каждый день — разные. Когда все предметы класса
сданы на «3» и выше, в конце дня ученика **переводят в следующий класс** и его уроки
переезжают на этаж выше. Класс можно выбрать в меню («🎓 Класс»).

### 🔬 Практические работы в специальных кабинетах

| Кабинет | Практика |
|---|---|
| ⚗️ Лаборатория химии (вытяжной шкаф, реактивы) | опыты: смешивание реактивов, индикаторы, осадки, выделение газа |
| 🧬 Лаборатория биологии (микроскопы, аквариум) | микроскоп: навести резкость и найти части клетки, клетки крови, бактерии |
| ⚡ Лаборатория физики (стенды, маятник) | сборка электрической цепи, подсчёт колебаний маятника, угол отражения |
| 💻 Компьютерный класс | программирование робота: последовательности и циклы |
| 🗺️ Кабинет географии (глобус) | поиск материков, океанов и России на карте |
| 📐 Геометрия | построение и измерение углов транспортиром |
| 🎨 ИЗО / МХК | рисование на холсте |
| 🎵 Музыкальный класс (пианино) | повторить мелодию на клавишах, держать ритм |
| 🛡️ Кабинет ОБЗР (огнетушители) | эвакуация из горящего здания, первая помощь |
| ⚽ Спортзал | **3D‑практика**: окно урока скрывается, и ученик бежит по залу через кольца на время (на оранжевых кольцах нужно прыгать), плюс упражнения на ритм |

К оборудованию в кабинете можно подойти и вне урока: подсказка «Провести опыт / Посмотреть
в микроскоп / Собрать цепь…» запускает практическую работу отдельно.

### 🚨 Миссия «Захват школы»

После **3-го урока** дня в школу врываются грабители (они появляются на трёх этажах). Уроки ставятся на паузу:
- грабители подсвечены красной меткой **сквозь стены** и отмечены на мини-карте, стрелка цели ведёт к ближайшему;
- в холле у лифта на каждом этаже стоит **ящик полиции**: снаряжение выдаётся за решённые примеры — свисток-сирена (легко), электрошокер (средне), сетемёт (сложно, дальность 10 м). Все средства нелетальные;
- **F**, левая кнопка мыши (при захваченном курсоре) или кнопка ⚡ на телефоне — задержать грабителя; задержанный сидит в наручниках. Грабители гоняются за игроком и толкают его;
- в кабинетах сидят **связанные заложники** — их можно освободить (E);
- когда все задержаны, выясняется, что в школе **бомба**: на время нужно решить три задачи и перерезать провода;
- у школы стоят **полицейские машины с мигалками** и полицейские, вход оцеплен лентой.

Логика миссии — `src/quests/Raid.js`.

### 📊 Информация (панель в стиле админки)

В главном меню и на паузе есть кнопка **«📊 Информация»**. Это панель, где видно всё, что делал игрок:
- **Обзор** — время в игре, число уроков, средняя оценка, точность ответов, монеты (заработано/потрачено), класс, уровень, достижения; графики результатов по предметам и активности по дням; последние действия.
- **Журнал действий** — каждое действие с точным временем: уроки, ответы на вопросы (верно/ошибка), практические работы, выполненные задания, переходы между локациями, взаимодействия (полил цветок, вызвал лифт…), покупки, достижения. Есть фильтры по типу и поиск.
- **Уроки и оценки** — история всех уроков (оценка, % верных, время, по расписанию или свободно), прогресс по всем 11 классам, распределение оценок.
- **Покупки и образ**, **Достижения** с датами.
- Кнопка **«Скачать отчёт»** сохраняет все данные в JSON-файл.

Журнал хранится в `localStorage` вместе с сохранением (последние 2000 записей). Запись делает `save.log(type, text, extra)`.

### Механики для интереса
- 🦉 Сова Соня — помощница, которая подсказывает, что делать дальше.
- 🔥 Комбо за ответы подряд, 💡 платные подсказки, 🔁 повтор урока.
- ⭐ 10 спрятанных «звёзд знаний», при каждой находке показывается интересный факт.
- 🏅 22 достижения, уровни опыта, оценки в дневнике, конфетти за хорошие результаты.
- 🔊 Озвучка текста и диктант голосом через Web Speech API. Если в браузере его нет, слово
  на пару секунд показывается на экране.
- 📅 Смена учебных дней: на каждый день берутся следующие уроки по кругу. Чтобы закончить день,
  нужно вернуться домой.
- Вся музыка и звуки синтезируются через WebAudio, внешние аудиофайлы не нужны.

## ➕ Как добавить новый урок или предмет

Уроки хранятся по предметам: `src/lessons/data/<предмет>.json`, внутри — урок для каждого класса.
Подключать файлы в коде не нужно: они собираются автоматически через `import.meta.glob`.

```json
{
  "subject": "physics",
  "lessons": {
    "7": {
      "title": "Механическое движение",
      "intro": "Здравствуйте! Сегодня изучаем скорость.",
      "read": [
        { "title": "Скорость", "pic": "🚗", "text": ["[[Скорость|Путь за единицу времени]]: **v = s / t**."], "tip": "Измеряется в м/с." }
      ],
      "practice": [
        { "type": "input", "q": "Поезд прошёл 180 км за 3 часа. Скорость?", "answer": ["60"], "explain": "180 : 3 = 60 км/ч" },
        { "type": "circuit", "q": "Собери цепь", "need": ["battery", "lamp", "switch"] }
      ]
    }
  }
}
```

- **Новый урок для класса** — добавьте ключ с номером класса в `lessons`. Предмет должен
  изучаться в этом классе по `curriculum.js`.
- **Новый предмет** — добавьте его в `SUBJECTS` (название, иконка, цвет, тип кабинета `kind`,
  учитель) и в `RANGES` (с какого по какой класс изучается) в `src/lessons/curriculum.js`, затем
  создайте JSON‑файл. Кабинет на нужных этажах появится сам: номер = этаж × 100 + порядковый номер.
- Типы кабинетов `kind`: `class`, `chem`, `bio`, `phys`, `it`, `geo`, `art`, `music`, `tech`,
  `obzr`, `gym` (спортзал на 1 этаже).

**Разметка текста:** `**слово**` выделяет слово цветом, `[[слово|подсказка]]` делает жёлтый термин,
по нажатию на который показывается подсказка.

### Типы заданий (`practice[].type`)

| type | Поля | Описание |
|---|---|---|
| `choice` | `q, options[], answer` | выбор ответа |
| `truefalse` | `q, answer: true/false` | верно / неверно |
| `input` | `q, answer` (строка или массив) | ввод ответа |
| `match` | `q, pairs: [[левое, правое], ...]` | сопоставление |
| `order` | `q, items[]` (в правильном порядке) | правильный порядок |
| `math` | `gen: {ops:["+","-","×","÷"], min, max, count}` или `gen.kind`: `eq`, `pow`, `sqrt`, `neg`, `dec`, `percent` | случайные примеры и уравнения |
| `dictation` | `words[], lang?` | диктант с озвучкой |
| `gap` | `text: "м_локо", options[], answer` | вставить букву |
| `chem` 🔬 | `goal, reagents[{id,name,color}], reactions[{mix:[id,id], color, ok, gas?, precipitate?, text}]` | химический опыт |
| `microscope` 🔬 | `specimen: plant/animal/bacteria/blood, find[]` | микроскоп |
| `circuit` 🔬 | `need[]` (battery, lamp, switch, ammeter, resistor), `options?`, `slots?` | электрическая цепь |
| `robot` 🔬 | `size, start, goal, walls[], loops?, maxCmds?, theme: robot/turtle/evac` | программирование робота / эвакуация |
| `map` 🔬 | `find[]` (материки, океаны, «Россия» + `showRussia`) | карта мира |
| `angle` 🔬 | `mode: build/measure, target?, tol?` | транспортир |
| `paint` 🔬 | `minColors, colors?, guide?` | рисование |
| `melody` 🔬 | `length` или `notes: ["до","ре"]` | повтори мелодию |
| `rhythm` 🔬 | `hits, speed, exercise, action` | ритм (прыжки, маятник, барабан) |
| `sport` 🔬 | `rings, jumps, limit` | пробежка по спортзалу в 3D |

Во всех заданиях можно указать `explain` (объяснение после ответа) и `hint` (платная подсказка).
Свой тип задания добавляется в `src/lessons/tasks.js`, а практический — в `src/lessons/practicals.js`.

## 🛍️ Как добавить предмет в магазин

Добавьте объект в `ITEMS` в `src/shop/items.js`:
- **образ (skin):** цвета `body`, `pants`, `shoes`, `hair`, `skinTone`, форма `shape`
  (`normal | round | tall | mini | robot`) и деталь `extra` (`tie, stripes, cape, robe, astro, dino...`);
- **аксессуар:** `slot` (`hat | glasses | backpack | watch | badge`), `model` (см. `buildHat`,
  `buildGlasses`... в `src/player/CharacterModel.js`) и цвета `color` / `color2`.

## ⚙️ Настройка баланса (`src/config.js`)

- `lesson.realSeconds` — сколько реальных секунд длится урок (по умолчанию 300 с = 30 игровых
  минут). Это значение также меняется в игре: Настройки → «Длина урока».
- `clock.*` — время пробуждения, скорость игровых часов, порог для «ранней пташки».
- `rewards.*` — монеты и опыт за ответы, комбо, бонусы, подсказки, находки.
- `lessonsPerDay` — сколько уроков в учебном дне.

## ⚡ Производительность

- Статическая геометрия каждой локации объединяется в несколько мешей по цветам
  (`BaseScene.finalize`). Так draw calls остаётся немного: на этаже школы около 90–130, на улице около 380
  вместе с тенями. Каждый этаж школы — отдельная локация, учителя дальних кабинетов не рисуются.
- Тени даёт одна направленная лампа, область теней следует за игроком.
- Режим «Быстрая графика» в настройках отключает тени и снижает разрешение рендера.
- В квартире верхний уровень скрывается, когда игрок внизу (режим «кукольного домика»), чтобы
  камере не мешал потолок.

## 💾 Сохранения

Прогресс (монеты, опыт, покупки, оценки, достижения, звёзды, текущая локация и шаг дня)
автоматически сохраняется в `localStorage`: каждые 15 секунд, при переходах между локациями и
при закрытии вкладки. Сбросить прогресс можно в разделе Настройки → «Сбросить весь прогресс».
